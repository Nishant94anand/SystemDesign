# System Design Learning Lab — Syllabus

This is the short entry point. The canonical curriculum and grounding baseline is **[Syllabus V2](SYLLABUS_V2.md)**.

| Phase | Focus | Evidence |
|---|---|---|
| 0 | Problem framing, NFRs, estimation, networking and reliability | Measurable requirements, assumptions and workload estimates |
| 1 | APIs, traffic, caching, data stores, async systems, storage and compute | Request/data traces and justified component choices |
| 2 | Distributed systems, correctness, partial failure and overload | Invariants and consistency/recovery reasoning |
| 3 | Applied system design exercises | Independent designs, estimates, failure analysis and alternatives |
| 4 | Production architecture, security, operations, migration, multi-region and cost | Testable operational, security, rollout and recovery plans |
| 5 | Staff/Principal architecture and technical leadership | Defensible decisions, ADRs, migration/ownership strategy and cross-team reasoning |
| Ongoing | Interview practice and spaced revision | Interview readiness assessed separately from production/Principal evidence |

Use [Syllabus V2](SYLLABUS_V2.md) for detailed topics, exit evidence, cloud-comparison policy, assessment scorecards and change control. Use the [Playbook](../docs/LEARNING_LAB_PLAYBOOK.md) for how to learn and publish; use [Progress](../progress/PROGRESS.md) to resume from demonstrated evidence.
