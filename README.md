## Simple operating model
- Continue the STARTED topic from the latest relevant Daily Log entry; otherwise take the next NOT STARTED row.
- A specifically requested topic can be studied out of sequence. Add out-of-syllabus topics under Misc / Ad-hoc.
- Concepts use intuitive stories followed by technical depth. Labs run as informal design interviews.
- At completion, summarize the session, create the full artifact, mark COMPLETED, add a rating out of 5, and link the row to the artifact folder.
- Do not pre-create empty topic folders or treat repository setup as learning progress.
