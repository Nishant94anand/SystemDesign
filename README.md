## Simple operating model
- Continue the STARTED topic from the latest relevant Daily Log entry; otherwise take the next NOT STARTED row.
- A specifically requested topic can be studied out of sequence. Add out-of-syllabus topics under Misc / Ad-hoc.
- Concepts use intuitive stories followed by technical depth. Labs run as informal design interviews.
- At completion, summarize the session, create the full artifact, mark COMPLETED, add a rating out of 5, and link the row to the artifact folder.
- Do not pre-create empty topic folders or treat repository setup as learning progress.

## Commands and visual notes
- **START TOPIC / START CHAPTER:** select the next eligible topic (or name one), calibrate with a question and mark STARTED when tracked.
- **CONTINUE / PAUSE TOPIC:** use Daily Log to resume/preserve the exact checkpoint.
- **COMPLETE TOPIC / COMPLETE CHAPTER:** with explicit consent, finish and verify the full chapter/lab, link it, then mark COMPLETED and rate discussion coverage out of 5; completion is not proof of mastery.
- Completed notes can use original **Mermaid architecture/sequence/flow diagrams, tables, formulas, images, flowcharts, traces and restrained emojis** when they improve understanding. See [Playbook's visual standards](docs/LEARNING_LAB_PLAYBOOK.md#chapter-visuals-diagrams-and-generated-assets).
