# System Design Learning Lab

A Markdown-first, interactive learning workspace for Staff/Principal-level System Design intuition and engineering judgment.

## Start here
1. Paste [Project Instructions](PROJECT_INSTRUCTIONS.md) into your ChatGPT Project Instructions. The file is designed to fit within the usual 8,000-character limit; verify the count in your Project UI.
2. Upload [the Detailed Playbook](docs/LEARNING_LAB_PLAYBOOK.md), [the Syllabus](curriculum/SYLLABUS.md), and [Progress](progress/PROGRESS.md) as Project reference files.
3. Keep the latest progress file updated. If the Project cannot access your repository directly, upload the latest copy when resuming.
4. Start a conversation called `00 — Learning Control Center`.

## Starter prompt
> Chalo bhai, apna System Design Learning Lab officially start karte hain! Pehle syllabus ko initialize karo, learning workflow samjhao, aur meri current understanding calibrate karne ke liye ek focused question poochho. Ek baar mein ek question; friendly Hinglish; relatable Indian/Bihar examples; theory plus practical depth. Abhi massive lecture mat dena. Progress ko `progress/PROGRESS.md` ke structure mein track karna.

## Documentation policy
- Markdown is the default for concepts, syllabus, progress, exercises, and revision.
- Prefer Mermaid diagrams for GitHub rendering.
- Use HTML only for specific presentation or offline requirements.
- Keep chapters modular; do not load the whole repository into every session.
- Never claim Drive/GitHub was updated unless it actually was.
