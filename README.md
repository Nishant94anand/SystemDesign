# System Design Learning Lab

A practical, interactive workspace for building Staff/Principal-level system design skills through discussions and design labs.

## Start here
1. [Project Instructions](CopilotInstructions/PROJECT_INSTRUCTIONS.md) — persistent tutoring style.
2. [Learning Workflow](CopilotInstructions/LEARNING_WORKFLOW.md) — continue/specific-topic rules and completion workflow.
3. [Syllabus V2](curriculum/SYLLABUS_V2.md) — canonical curriculum; it remains unchanged.
4. [Progress](progress/PROGRESS.md) — one ordered Topics table with phase, topic, status and rating.
5. [Daily Log](progress/DAILY_LOG.md) — dated summaries used to resume a discussion.
6. [Design Exercise Template](design-exercises/TEMPLATE.md) — used when a lab is completed.

## Simple operating model
- Continue the STARTED topic from the latest relevant Daily Log entry; otherwise take the next NOT STARTED row.
- A specifically requested topic can be studied out of sequence. Add out-of-syllabus topics under Misc / Ad-hoc.
- Concepts use intuitive stories followed by technical depth. Labs run as informal design interviews.
- At completion, summarize the session, create the full artifact, mark COMPLETED, add a rating out of 5, and link the row to the artifact folder.
- Do not pre-create empty topic folders or treat repository setup as learning progress.
